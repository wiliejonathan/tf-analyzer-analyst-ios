TF Analyzer Analyst - iOS PWA - GitHub Pages READY

UPLOAD CONTENTS OF THIS FOLDER TO THE ROOT OF A GITHUB REPOSITORY.
Do not upload the outer folder itself as an extra nested level.

Required root files include:
- index.html
- manifest.webmanifest
- service-worker.js
- .nojekyll
- assets/
- icons/
- mobile-*.js / mobile-*.css

Recommended repository name:
tf-analyzer-analyst-ios

Then:
GitHub Repository -> Settings -> Pages -> Build and deployment
Source: Deploy from a branch
Branch: main
Folder: / (root)
Save

Expected project URL pattern:
https://<github-username>.github.io/tf-analyzer-analyst-ios/

Customer iOS installation:
1. Open the published link in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Tap Add.
5. Open TF Analyzer Analyst from the Home Screen.
